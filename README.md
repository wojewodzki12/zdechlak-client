# ZDECHLAK Client

Public Windows x64 OTClient package and signed update channel for [zdechlak.pl](https://zdechlak.pl).

## Download (current)

**https://github.com/wojewodzki12/zdechlak-client/releases/tag/v1.0.2**

Extract and run `ZDECHLAK Launcher.exe`.

> v1.0.0 / v1.0.1 launchers are broken on clean Windows (`libwinpthread-1.dll`). Use **v1.0.2+**.

## Update channel

`https://raw.githubusercontent.com/wojewodzki12/zdechlak-client/updates/v1`

Launcher auto-checks this endpoint on every start (signed Ed25519 manifests).
